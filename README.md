# Retail Sales Analysis Dashboard (Excel)

## Project Overview
This project analyzes retail sales data using Microsoft Excel Pivot Tables, Pivot Charts, Slicers, and Timeline filters.

## Features
- Sales by Region Analysis
- Profit by Category Analysis
- Customer Segment Analysis
- Monthly Sales Trend Analysis
- Region vs Category Matrix
- Top 10 Products by Sales
- Bottom 10 Products by Profit
- Discount Impact Analysis
- Salesperson Performance Analysis
- Payment Mode Analysis
- Interactive Dashboard with Slicers and Timeline
- Business Insights and Recommendations

## Tools Used
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Slicers
- Timeline Filters
- Dashboard Design

## Key Insights
- South Region generated the highest sales.
- High discounts reduced profit margins.
- Top-selling products contributed significantly to revenue.
- Digital payment methods were widely preferred by customers.
- Customer satisfaction remained positive with an average rating of 3.97.
